Chronova Studio · Chronova History AI

Privacy Policy

Last updated 22 November 2026

Chronova Studio is an independent creative project focused on history and education. This policy covers the Chronova public website, the Chronova History AI connector on Muse, and messages you send to our support address.

What the connector receives

When you use a tool, Muse sends a request to our connector on Cloudflare Workers. The request includes a method, a request identifier when applicable, and any arguments for that tool.

  • create_history_short uses the historical topic you enter and, if provided, a duration and language label. The tool returns a four-part text outline to Muse. The outline includes the supplied topic, a duration, and a language label. Scene instructions are in English. Please use historical subject matter and leave out private details about yourself or other people.
  • get_studio_info returns a fixed description of Chronova Studio and its capabilities. It requires no user input.

The tools work without a Chronova account, password or API key. The Worker builds the response in memory. Its application code has no database for topics or outlines, makes no calls to external AI providers, and does not write the request body or the outline to an application log.

Operational logs and retention

We use Cloudflare Workers Logs to check whether the connector responds and to diagnose errors. Invocation logging is enabled. Log entries can include the request time, HTTP method and URL, response status, request identifiers, network and user-agent information, and the Cloudflare location that handled the request. The network address can belong to the service making the request on your behalf. Keep personal information out of request URLs.

For Workers Free, Cloudflare documents a three-day retention period for Workers Logs through 30 November 2026. Its published Free Observability plan lists seven days from 1 December 2026. These periods describe logs available in Cloudflare’s logging service. They do not set a deletion deadline for support email, copies held by Muse, or any separate provider backup. The Worker has no configured external log export destination. The developer keeps no separate exports, screenshots or personal backups of Muse users’ personal data.

Service providers and international processing

One independent developer administers Chronova from Indonesia and has no separate servers or personal backups for the connector. Muse sends the tool request and receives the result. Cloudflare, Inc. hosts the Worker and its operational logs. The Worker uses Cloudflare’s default placement. Requests for this connector have been handled in the United States and the Netherlands. Cloudflare’s Data Localization Suite is not enabled on this account. Requests can be processed in other countries, and Cloudflare may store invocation logs in its core data centers worldwide. A request’s processing location does not establish where its log is stored.

For covered personal data, Cloudflare incorporates its Customer Data Processing Addendum into its self-serve terms. The addendum provides safeguards depending on the transfer, including Standard Contractual Clauses for applicable restricted European transfers and the Data Privacy Framework for qualifying US transfers.

GitHub Pages hosts the public Chronova website and can process technical information when you visit it. The connector processes tool requests on Cloudflare. If you email us, our email provider handles your address, your message and anything you choose to attach so we can respond.

Request access or deletion

The developer monitors the privacy inbox. Email m11510n01@gmail.com to ask about personal data Chronova holds or request access or deletion. Tell us whether your request concerns a support email or a connector call. For a call, an approximate time, time zone and tool name can help us locate the event. Please leave out passwords, ID documents and the original text of any sensitive prompt.

We can review a request against records we can identify and may need to verify that they relate to you. The connector has no self-service deletion tool or user-account history. Some technical records identify the calling service and cannot be matched to a particular person. Log expiry is separate from a request to delete a record. Chronova currently has no verified way to erase an individual Workers Logs entry on demand. For a copy of a conversation or outline kept in your Muse account, direct your request to Muse.
