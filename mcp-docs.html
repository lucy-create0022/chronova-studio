Chronova History AI

Official MCP Server Documentation

Overview

Chronova History AI is an experimental Model Context Protocol (MCP) connector developed by Chronova Studio.

The connector provides structured historical storytelling templates for educational short-form videos.

MCP Endpoint

https://chronova-history-mcp.haimintol02.workers.dev/mcp

Connection

Protocol: MCP over HTTP (JSON-RPC 2.0).

Transport: Stateless HTTP, JSON responses.

Authentication: Not currently required.

Available Tools

1. create_history_short

Creates a structured outline for an animated historical YouTube Short.

Parameters:

  • topic: Required string.
  • duration: Optional integer, 15-180 seconds.
  • language: Optional string, default English.

Example MCP request:

{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "create_history_short",
    "arguments": {
      "topic": "How Napoleon Sold Louisiana",
      "duration": 60,
      "language": "English"
    }
  }
}

2. get_studio_info

Returns information about Chronova Studio and its current capabilities.

Access Requirements

  • No account currently required.
  • No API key currently required.
  • No paid subscription required.
  • Usage subject to Cloudflare Workers limits.

Current Limitations

This is an experimental connector. It provides structured templates, not finished videos or verified historical research.

It does not currently generate MP4 files, narration audio, or AI images.

Streaming SSE and user authentication are not currently implemented. Compatibility with all MCP clients is not guaranteed.

Security

The endpoint is intended for testing. Public production use requires further security review.
